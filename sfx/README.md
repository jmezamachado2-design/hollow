# SFX

Coloca archivos de sonido aquí (`.ogg`, `.wav` o `.mp3`). El nombre del archivo debe coincidir con el argumento de `AudioManager.reproduce_sfx()`.

Ejemplos: `hit.ogg`, `land.wav`, `hurt.ogg`, `heal.ogg`, `collect.ogg`, `death.ogg`, `ui.ogg`, `jump.ogg`

Si falta un archivo, `AudioManager` usa un tono procedural de respaldo.
